# 📁 Dossier .context

Ce dossier contient la documentation et l'analyse du projet pour faciliter l'onboarding et la compréhension de l'architecture.

## 📄 Fichiers

- **ANALYSE_PROJET.md** - Analyse complète du projet, stack technique, architecture, et guide pour webdesigner/front dev

## 🎯 Objectif

Ce dossier sert de référence pour :
- Comprendre rapidement la structure du projet
- Identifier les technologies utilisées
- Trouver les points d'entrée pour commencer à travailler
- Comprendre les patterns et conventions du code

## 🔄 Mise à jour

Ce dossier devrait être mis à jour lorsque :
- De nouvelles technologies sont ajoutées
- L'architecture change significativement
- De nouveaux patterns sont introduits
- Des fonctionnalités majeures sont ajoutées
